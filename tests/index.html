G. Filter and Special Cases

30. Intentional duplicate

Test: exactly two image elements with the same normal JPG URL. Source: Image elements = ON. Type: JPG = ON. Expected: Coffee.jpg appears twice when Ignore duplicates = OFF, and once when it is ON.

31. Hidden images and opacity counterexample

Test: hidden image elements, a hidden CSS background, and an opacity-only image. Source: Image elements and CSS background images = ON. Type: JPG = ON. Expected: with Ignore hidden images = OFF, all five candidates appear. With it ON, the display-none, visibility-hidden, hidden-parent, and hidden-background candidates do not appear; the opacity:0 candidate still appears.

H. CSS Blur Metadata

Setup: Image elements and Data images = ON; JPG, PNG and SVG = ON. Expected: A through E always appear. CSS blur is recorded only as visuallyBlurred: A through C are true; D and E are false.

32. Direct blur on image

33. Blur on direct parent

34. Blur on nested ancestor

Test: filter: blur(5px) on a deeply nested ancestor. Expected: included with visuallyBlurred = true.

35. Zero blur counterexample

Test: filter: blur(0px). Expected: included with visuallyBlurred = false.

36. Brightness-only counterexample

37. Same URL in blurred and unblurred contexts

Test: the same Data SVG URL first occurs under filter: blur(5px), then without blur. Expected: both occurrences are found. With Ignore duplicates = ON, the final candidate remains and has visuallyBlurred = false.
